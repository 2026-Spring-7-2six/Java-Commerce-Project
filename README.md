# Java Commerce Project

상품, 카테고리, 고객, 장바구니 및 주문을 관리하는 콘솔 기반 커머스 플랫폼 프로젝트.

기본적인 상품 관리 시스템을 구현한 뒤, 장바구니 및 주문 기능과 관리자 기능을 추가하고 Enum, 제네릭, 람다식 및 Stream API를 활용하여 기능을 확장하였음.

이후 JSON 데이터 입출력, 공통 출력 인터페이스, 상품 정렬 및 키워드 검색 기능을 추가하여 개선함.

## 개발 환경

- **Language:** Java 21
- **IDE:** VS Code
- **Libray:** Gson 2.15.0

## 프로젝트 기능

### 기본 기능

객체지향 설계를 적용하여 상품 관리 시스템의 기본 구조를 구현

- `Product` 클래스를 활용한 상품 정보 관리
- `Category` 클래스를 활용한 카테고리 및 상품 목록 관리
- `Customer` 클래스를 활용한 고객 정보 관리
- 카테고리별 상품 목록 조회 및 상품 선택
- 상품 재고 정보 확인
- `CommerceSystem` 클래스로 비즈니스 로직 및 사용자 입력 처리
- `AdminSystem` 클래스로 관리자용 비즈니스 로직 처리
- Getter와 Setter를 활용한 캡슐화 적용

### Lv1. 장바구니 및 주문 관리

장바구니에 상품을 추가하고 주문 및 주문 취소를 처리하는 기능

- 상품 선택 후 장바구니 추가 여부 확인
- 장바구니 상품 조회 및 수량 관리
- 동일 상품 추가 시 기존 장바구니 항목의 수량 증가
- 장바구니 상품 및 총 주문 금액 출력
- 주문 확정 및 상품 재고 차감
- 주문 취소 기능
- 장바구니 상태에 따른 주문 관리 메뉴 출력
- 재고 부족 및 잘못된 사용자 입력에 대한 예외 처리

### Lv2. 관리자 모드

관리자 인증을 통해 상품을 추가, 수정, 삭제하고 전체 상품 현황을 관리하는 기능

- 관리자 비밀번호 인증
- 비밀번호 인증 3회 실패 시 메인 메뉴 복귀
- 카테고리 선택 후 상품 추가
- 동일 카테고리 내 상품명 중복 검사
- 키워드 검색을 통한 상품 정보 수정 및 삭제
- 상품 삭제 전 확인 절차
- 삭제된 상품의 장바구니 항목 동기화
- 전체 상품 현황 조회

### Lv3. Enum, 제네릭, 람다 & 스트림 활용

Java의 다양한 문법을 활용하여 기존 기능을 확장하고 공통 기능을 분리

- Enum을 활용한 고객 등급 및 할인율 관리
  - BRONZE: 0%
  - BASIC: 5%
  - PRO: 10%
  - VIP: 15%
- 주문 확정 시 고객 등급에 따른 할인 적용
- Stream API를 활용한 상품 목록 조회
- 상품 가격을 기준으로 한 필터링
  - 100만 원 이하 상품
  - 100만 원 초과 상품
- 람다식과 `removeIf()`를 활용한 장바구니 개별 상품 제거
- 제네릭과 `Function`을 활용한 공통 기능 분리 및 재사용성 개선

## Plus. 추가 기능 및 코드 개선

### Printable 인터페이스

공통 인터페이스를 활용하여 객체별 출력 형식을 정의하고 출력 코드 재사용성 개선

- Printable 인터페이스 생성 및 toFormattedString() 메서드 선언
- Product, Category, CartItem, Grade 에 Printable 구현
- Utility 클래스에 제네릭 T extends Printable 을 적용한 공통 출력 메서드 구현

### JSON 상품 데이터 입출력

Gson 라이브러리를 활용하여 상품 데이터를 JOSN 파일로 저장하고 불러오는 기능 구현

- Gson 라이브러리를 활용한 객체 직렬화 및 역직렬화
- JsonStorage 클래스를 통한 JSON 파일 입출력 관리
- 프로그램 시작 시 JSON 파일에서 카테고리 상품 데이터 불러오기
- 최초 실행 시 기본 상품 데이터를 생성하고 JSON 파일 초기화
- 상품 추가, 수정, 삭제, 주문 시 변경된 데이터 저장

### 상품 정렬 및 키워드 검색

Stream 과 Comparator 를 활용하여 상품 정렬 및 키워드 검색 기능 구현

- 상품명 가나다 순 정렬
- 가격 오름차/내림차 정렬
- 재고량 오름차/내림차 정렬
- 관리자 상품 수정 및 삭제 시 상품명 및 상품 설명을 대상으로 키워드 검색

## 프로젝트 구조

`Main` : 초기 카테고리 및 상품 데이터 생성, 프로그램 시작
`CommerceSystem`: 사용자 메뉴 및 커머스 비즈니스 로직 관리
`AdminSystem`: 관리자 인증 및 상품 관리
`Category`: 카테고리 정보와 상품 목록 관리
`Product`: 상품 정보 및 재고 관리
`Customer`: 고객 정보 관리
`Grade`: 고객 등급 및 할인율 관리
`Cart`: 장바구니 항목 관리
`CartItem`: 장바구니 상품 및 수량 관리
`Utility`: 공용 메서드 관리
